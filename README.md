# Jarvis AI Assistant

Asistent AI personal în stil Jarvis, 24/7, hibrid local + cloud, cu control vocal/Siri.

## Capabilități
- Notion task management
- Daily briefing automat
- Import orar PDF -> Calendar
- Voice pipeline: Whisper + Ollama + Piper
- Cloud fallback: Groq + LiveKit realtime

## Quick start
1. Urmează `/home/runner/work/jarvis-ai-assistant/jarvis-ai-assistant/docs/SETUP_LOCAL.md`
2. Configurează variabilele din fișierele `.env.example`
3. Rulează `docker compose up --build`
